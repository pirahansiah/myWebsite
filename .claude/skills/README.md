# Skills — On-Demand Workflows

Specialized, multi-step workflows. Load with `read_file` on the SKILL.md file in each subdirectory.

## Available Skills

- **collect-and-label** — Auto-capture from webcam, SAM2 labelling, YOLO dataset prep
- **benchmark-model** — Latency/throughput profiling, FP32 vs INT8 comparison  
- **debug-quantization** — Fix INT8 accuracy, calibration, QAT, hardware compatibility
- **full-pipeline** — End-to-end capture → label → train → export → quantize → build
- **platform-porting** — Windows-to-macOS/Linux code conversion; PyObjC patterns for mouse/screen APIs
