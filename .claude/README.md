# .claude — Project Agent Workspace

This folder contains project-level Claude/agent configuration: rules, skills, agents, and memories used to guide automated assistants and workflows for this repository.

Key files:
- `CLAUDE.md` — project brain (quick-start, conventions)
- `CLAUDE.local.md` — local overrides (machine-specific)
- `rules/` — coding and domain rules loaded on each task
- `skills/` — on-demand workflow documents
- `agents/` — agent personas
- `agent-memory/` — persistent project memories

Use `requirements.txt` to provision a Python environment for local scripts.
