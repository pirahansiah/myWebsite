# Agents — Specialist Personas

Specialized subagents for complex, autonomous tasks. Invoke with `runSubagent` tool.

## Available Agents

- **code-reviewer** — Code quality, security, maintainability review
- **cv-ml-expert** — Computer vision, YOLO, ONNX, quantization, inference optimization
- **data-prep** — Dataset preparation, validation, augmentation
- **debugger** — Errors, test failures, unexpected behavior diagnosis
- **optimizer** — Performance optimization, profiling, bottleneck analysis
- **researcher** — Literature search, documentation, external validation
- **security-auditor** — Security review, vulnerability scanning, auth/data handling

## Usage Pattern

```
Use when task requires autonomy and specialized domain expertise.
Do not use for single-step operations or simple queries.
```
