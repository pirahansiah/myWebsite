Underfitting vs Overfitting

Underfitting (reducing bias): - Bigger model - Reduce regularization - Error analysis - Different model architecture - Tune hyper-parameters - Add features

Overfitting (reducing variance): - Add more training data - Add normalization (batch norm, layer norm) - Add data augmentation - Increase regularization (dropout, L2, weight decay) - Error analysis - Choose different model architecture - Tune hyper-parameters - Early stopping - Remove features - Reduce model size
