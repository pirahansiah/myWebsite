# Solana Arcade — Snake & Tetris

**◎ [Play Snake and Tetris](/farshid/content/solana-games.html)** — connect Phantom, play, then sign your best score. Signing is a message signature only: it is free, sends no transaction and spends no SOL.

A markdown page cannot run scripts, so the playable arcade is a standalone page: <https://pirahansiah.com/farshid/content/solana-games.html>. This file is its description and stays readable to crawlers and language models.

- **Snake** and **Tetris**, keyboard, swipe or on-screen controls, with local high scores.
- **Phantom wallet** connection to prove the address that earned a score; no account and no install.
- **Signed proof** — the score is signed as a message anyone can verify against the public key.
- Runs entirely in the browser, including inside Telegram; nothing is uploaded.
