# Agent Swarm

Agent Swarm — ask a question and watch a live swarm of research agents map and synthesize the whole pirahansiah.com knowledge base.

> Agent Swarm is an interactive tool: ask a question and a swarm of AI research agents explores the site — papers, journals, books, patents, keynotes, courses, CV — maps the knowledge graph, and synthesizes an answer with related pages, tags, and relations.

## What it does

- **Ask anything** — e.g. camera calibration, optical flow, multi-agent LLMs, patents, OpenCV 5
- **Live swarm animation** — each node is an agent with a specialty: text retrieval, graph mapping, tag mining, categorization, relation weaving, synthesis
- **Swarm synthesis** — key points, categories covered, top tags, related pages, and relations between findings
- **Dynamic knowledge graph** — built live for your question (blue = pages & publications, purple = tags, grey = categories)
- **Ready-to-post X summary** — copy or open in X

This tool runs in-browser against the site index and knowledge graph. It previously lived at `/swarm/`.
