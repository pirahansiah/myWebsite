# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain static HTML/CSS/JS; no dependencies. User-selected. Standalone project; do not modify or integrate into the main website.

## Users

Prospective clients, collaborators, and technical readers who want to explore Dr. Farshid Pirahansiah’s work and open relevant pages.

## Product Purpose

An interactive, motion-graphic web experience that introduces Farshid and provides a navigable gateway to every page in the existing website. Success means visitors can understand the breadth of the work and find/open any listed page.

## Positioning

The experience is a standalone animated index to the existing site, not a replacement for the site or its source pages.

## Operating Context

Visitors arrive to explore a personal portfolio and technical knowledge collection, then follow links to the canonical website pages. The project lives only in `farshid/projects/html-motion-graphic/`.

## Capabilities and Constraints

Use static HTML, CSS, and JavaScript without dependencies. Include all pages enumerated in the site's sitemap as of the build. Existing source pages and site files are read-only and must not be changed. The experience should work as a static project and link out to canonical pages.

## Evidence on Hand

The existing website repository provides `sitemap.xml`, page markdown, the Atlas, and site identity/content. These are the source of truth for page coverage and labels; do not invent credentials, clients, testimonials, or performance claims.

## Product Principles

- Keep existing website content and destinations authoritative.
- Make the full breadth discoverable without overwhelming visitors.
- Let visitors move from animated overview to direct page links.
- Keep motion optional and preserve usability when motion is reduced or unavailable.
