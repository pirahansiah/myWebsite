# Surface brief — HTML motion graphic

Scope: Standalone static web experience. Mode: Experience.

Audience and job: Prospective clients, collaborators, and technical readers explore Farshid Pirahansiah’s work and open relevant pages. Success means the collection is legible at a glance and every sitemap entry is reachable by search, category, or direct selection. Use the 105 entries in the existing sitemap as the source of truth.

Constraints: This project is isolated in `farshid/projects/html-motion-graphic/`; all source site files are read-only. No dependencies or invented claims. Keep canonical destinations and the existing Ubuntu/Yaru/GNOME visual identity. Motion must be optional, accessible, and subordinate to page discovery.

## Direction contract

THESIS: Replace a static all-pages list with a navigable constellation where the full collection is visible and every node opens its real page.

OWN-WORLD: Extend the existing Ubuntu desktop window: aubergine wallpaper, flat Yaru light surfaces, Ubuntu Sans, hairline structure, and Yaru orange as the interaction accent. No new visual identity.

STORY: Visitors see the breadth of the collection, focus a topic or search, inspect a page, then open its canonical rendered destination.

FIRST VIEWPORT: A GNOME-like window fills the display. The header introduces the site and offers search and an all-pages count. A spacious SVG field groups 105 labeled nodes into eight named topic regions; a compact detail rail shows the selected page. Category filters and a complete, accessible result list follow the map.

FORM: User-pinned animated knowledge constellation with search, category filters, selectable nodes, and canonical links; it overrides the catalog roll. Seed key: 58c660ea.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Unresolved: None for the first implementation.
